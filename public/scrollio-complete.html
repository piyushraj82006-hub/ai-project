System Architecture

How ScrollIO processes documents and delivers AI-powered study materials

🔐

Authentication Layer

Local auth system with email/password sign-in, sign-up, and session persistence via localStorage. Google OAuth available in production.

📄

PDF Processing Engine

PDF.js extracts text from standard PDFs. For scanned documents, the file is converted to base64 and sent to Gemini Vision API for OCR extraction.

🤖

Dual AI Engine

Gemini API generates structured summaries, mind map data, and reels. Groq's Llama 3.1 powers the high-speed chatbot with context.

🧠

Visualization Layer

D3.js renders interactive radial mind maps. React Markdown with KaTeX renders LaTeX equations. Summary uses structured JSON rendering.

🎬

Reels Generator

AI distills documents into Instagram-style educational cards with titles, content, and key points. Swipeable carousel with download support.

💾

Storage & History

LocalStorage persists user data, summaries, and reels. Dashboard displays history with one-click reload and delete functionality.
